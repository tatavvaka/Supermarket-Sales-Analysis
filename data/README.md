# Dataset Source

Dataset utama merupakan synthetic Indonesian supermarket transaction dataset dengan periode pemesanan 3 January 2014 hingga 30 December 2017.

Workbook sumber berisi worksheet `sources`, `README`, reference tables, pivot analysis, dan supporting summaries.

- [Google Sheets — Dataset & Analysis Workbook](https://docs.google.com/spreadsheets/d/10lisgzLeKctiXgy_6snTHfIs6_QuAsASzLCqs5beRBs/edit?usp=sharing)
- [Data Dictionary](../docs/data-dictionary.md)
- [Data Quality Notes](../docs/data-quality.md)

Dataset ini bersifat sintetis. Jangan menginterpretasikan record sebagai transaksi pelanggan atau supermarket nyata.
